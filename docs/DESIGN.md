# 界面设计

目的：单手快速记账，随时看清当前月份收支。使用原生 Material3 交互和系统中文字体；无远程字体、图片或营销文案。

## 设计 token

- 纸白背景：`#F7F9F8`，轻微绿色让界面有账本气质，不使用装饰渐变。
- 深青主色：`#176B5B`，用于主要动作与收入。
- 墨色正文：`#182A25`，金额与主要文字有稳定对比。
- 支出色：`#A74335`，以“-”号和“支出”文字同时表达类型，不能仅靠颜色区分。
- 分隔色：`#D9E4DF`，区分日期组和条目。
- 白色表面：`#FFFFFF`，仅关键汇总区及编辑表单使用，不把所有内容切成相同卡片。

类型：系统Sans中文字体；标题22sp，主要金额28..32sp，正文16sp，辅助标签14sp。数字右对齐，最小触摸目标48dp；系统字体缩放后保持可操作。不得固定屏高或让键盘挡住保存动作。

## 结构

```text
安记账                       记一笔
          ‹ 2026年10月 ›     本月
收入 ¥100.00   支出 ¥12.35
本月结余 ¥87.65
────────────────────────────
10月04日
餐饮       午饭             -¥12.34
交通                       -¥0.01

           账目  统计  设置
```

“记一笔”始终容易找到。空状态：“这个月还没有账目”，按钮“记一笔”。统计显示支出分类金额及占比条，收入、支出和结余并列可读。设置只展示备份/恢复、本地隐私和版本/许可证。

编辑表单先选收支类型，再填金额、日期和分类，备注可选。错误直接说明修正动作，例如“金额请输入0.01至999999999.99，最多两位小数”；保存失败保留输入。删除对话框指明将删除哪笔账目。

导出说明“备份文件包含明文账目，请保存在可信位置”。恢复说明合并而非替换，显示成功新增/跳过数量；失败说明原数据保留。产品界面不暴露数据库、协程等开发术语。

首次评审：收支软件适合少量数字汇总，不采用网页hero、宣传段落、照片或连续卡片。颜色同时有类型文字和符号作为冗余，布局对齐为读账服务。最终视觉验收以安卓运行截图和作者手机体验为准。
