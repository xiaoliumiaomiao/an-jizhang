# 首版需求与验收

作者确认日期：2026-10-04。名称：安记账。目标：中文、离线、无需登录的安卓本地收支账本。

## 功能

- Android 8.0 / API 26 及以上；默认 CNY 人民币。
- 新增、编辑、删除收入或支出；金额、分类、日期、可选备注。删除需确认。
- 内置分类并允许在记账时输入自定义分类；不同收支类型提供对应建议。
- 按月份浏览，切换上月/下月/本月。显示收入、支出、结余、支出分类汇总。结余允许负数。
- 数据保存在应用私有 SQLite 数据库；关闭或重启应用后保持。
- 通过系统文件选择器导出 JSON 备份和导入恢复；明文备份，导出前提醒妥善保管。
- 恢复采取合并：相同 ID 且内容相同跳过；相同 ID 内容不同整批拒绝；损坏、非法或不兼容备份不修改现有账目。
- 设置页说明本地隐私、卸载数据风险、备份操作、版本与第三方许可。

## 数据合同

记录 `Entry(id: String, kind: EntryKind, amountCents: Long, category: String, date: LocalDate, note: String)`；类型 `EXPENSE`/`INCOME`；ID 是 canonical UUID。

金额限制：0.01 至 999999999.99 元，即 `MAX_CENTS = 99999999999L`。输入只接受十进制非负数字和最多两位小数，允许首尾空白；不允许零、负数、科学计数法、逗号。统计使用 Long 安全加法。

分类修剪后 1 至 20 字符；备注最多 200 字符。日期有效且年份为 1900 至 9999。记录按日期倒序排列，日期相同按 ID 稳定排序。

备份根对象：`{"format":"an-jizhang","version":1,"currency":"CNY","entries":[...]}`。记录字段为 id、kind、amountCents、category、date（ISO yyyy-MM-dd）、note。最多 50000 条，UTF-8 输入最多 10 MiB；禁止重复 ID；金额字段必须 JSON 整数；解析整批验证后才进入数据库事务。

## 验收场景

1. 输入 0.01、12.34 正确保存；0、-1、1.234、1e2、超限金额被拒绝。
2. 2026-10 收入 100.00、餐饮支出 12.34、交通支出 0.01：收入100.00、支出12.35、结余87.65；2026-09记录不进入10月统计。
3. 编辑金额与类型后汇总更新；确认删除后账目消失；重开数据库后内容仍一致。
4. 导出并导入另一空库恢复全部记录；重复导入新增0条；ID冲突、损坏文件、超限或未知版本整批拒绝且旧数据不变。
5. Manifest 无联网/广泛存储权限，自动云备份关闭；APK 可编译并通过 Android lint。
6. 作者手机自然验收单独记录，不能以 JVM、Robolectric 或静态检查代替。

首版不扩展多账户、转账、同步、自动读取短信、支付平台导入、预算、广告及商店发布。
