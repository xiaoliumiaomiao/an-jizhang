## 本轮待验项目

- [ ] 正常覆盖安装 fix1/code5 后，原账目条数、金额、收入/支出类型、分类、日期、备注和跨月统计保留。
- [ ] 新建两笔可辨认测试记录；只删除其中一笔，“已删除”出现后约 3 秒自动消失，无需重启，另一笔和原账目仍保留。继续操作后旧提示不会长期挂在页面。
- [ ] 新建/编辑时点击金额栏，应用内数字键可用，首次及重复点击不唤起系统输入法；数字按顺序追加到末尾。
- [ ] 实际使用小数点、退格及清空，金额显示与操作一致；从空金额输入 0.01 并保存，列表与当月统计准确增加一分钱。非法/未完成金额不会绕过原保存校验。

- [ ] 手机系统字体调大后数字、小数点、退格、清空和主要字段清晰可点；在手机窄屏上滚动能到达全部键和保存/取消，没有遮住关键文字或无法触达的按钮。备注键盘出现时也可正常滚动及返回收键盘。
- [ ] 保存与删除的忙碌保护、取消/返回及出错后输入保留没有退化；关闭再打开应用后，已保存的一分钱及其他测试账目结果仍正确。
