## 3. 图表主导的统计顺序与数据合同

```text
期间选择（月／年与日期范围）＋紧凑收入／支出／结余
真实趋势（月每日收支；年十二月收支双柱）＋图例／准确数据
收入／支出类型选择＋所选类型分类环图
同一数据的分类横条与准确金额列表 → 精确分类钻取
同期比较＋笔数／笔均＋较大三笔＋月明细入口／范围说明
```

1. **月每日趋势：** 为所选月每个实际日历日提供收入／支出两组非负整数分，补齐无记录日为零，保留 28／29／30／31 天、月边缘和闰年。Canvas 原创绘制两条易区分的趋势线与必要点位；零数据不伪造非零趋势；单个非零日与仅单一收支类型也须有清楚点位和准确文字。轴／图例／语义及文字数据由同一模型生成，稀疏视觉刻度不得省掉真实日数据；未来日期与现有提示一致，不画预测值。
2. **年十二月双柱：** 固定 1–12 月，每月收入／支出双柱采用共同尺度，不省略零月。选择月份沿用原月统计入口。全年总额来自完整年，柱图和文字月份金额一致；未来月保持明确标识，1900／9999 导航不越界。
仅分类环图将排序前5类以外的金额按Long精确求和为“其余（N类）”视觉扇区；该汇总没有真实分类键、没有点击或下钻动作，不写入账本。完整横条与准确列表仍按原稳定排序逐类提供金额、占比、笔数及精确下钻；用户自定义“其他”仍是正常可下钻类别。聚合仅用于避免细碎扇区和拥挤图例，不改变分类数据。

3. **同类型分类环图：** 环图、横条与精确列表都取当前选中收入或支出的稳定分类排序；分母是完整所选期间本类型总额。中心显示类型与分类占比，下方显示完整准确总额，不混算收入＋支出。单分类为 100%，空类型展示文字空态而非假环；小分类保持原数据，不以视觉合并“其他”改变下钻语义。
4. **准确列表与下钻：** 分类金额和一位小数显示比例沿用既有精确舍入；同金额按现有稳定规则排序。保留“餐饮”与“餐饮外卖”、首尾空白归一键、同名不同收支类型的准确范围；图形选择如有实现须只改变对应分类上下文，不能借用主明细搜索。原下钻 testTag 与返回滚动位置保留。
5. **可访问性与边界：** 图表标记及 semantics 给出期间、类型、日期／分类、准确金额及占比，文字列表始终可达；不能只通过颜色区别收支。采用相同模型生成图形与文本，零分母、1 分、MAX、多笔大总额、负结余和异常聚合先验证。绘制投影需要有限范围，不能产生 NaN／Infinity、越界柱／线或不可点击的标签。

不增加复杂图表手势、图片导出、远程素材或持久化图表设置；新图形为原统计派生数据，不新增数据库字段。来源与不引入 Vico 的决定见 [复用记录](../../REUSE_V017.md)。
