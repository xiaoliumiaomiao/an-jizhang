# 安记账 0.1.3 设计规格

状态：实施设计；本文件描述目标，不预填技术测试或手机验收通过。本稿以已验收 0.1.2 commit `ff8479f75cd917bc49e5ab2173ad7e9906dc480c` 为直接基线；本轮目标版本 `0.1.3/code4`。

## 1. 产品目标与边界

用户要求“界面重构和系统功能拓扑结构调整，具体方案参照市面已成熟软件方案”。本轮让四条路径清楚且一致：查看明细、记一笔、看月统计、本地备份。保留现有收支、分类、自定义分类、日期、备注、筛选、月份、CRUD、备份恢复、许可和隐私告知。新增日期分组、账目详情及全屏编辑作为呈现层行为。

不新增多账本、资产、预算、账户、云同步、登录、联网、遥测、广告、货币、账本加密和应用锁；不改变业务规则、数据库 schema1、备份 format1、整数分金额、applicationId 和 Android8/minSdk26。没有第三方字体、图标库、Navigation 库或 chart 依赖。主入口保留单 Activity、单 LedgerViewModel。呈现层只扩展 failedOperationId 和 VM 实例身份：前者按失败结果释放提交锁，后者识别恢复时已不存在的后台任务；不改变数据库操作和业务校验。

## 2. 成熟软件模式的采纳规则

以正式 [REUSE_V013.md](REUSE_V013.md) 及其中已验证的官方来源为证据。钱迹的明细优先及稳定记账动作、Realbyte Android 的交易/统计分离及备份归入设置，支持任务分区；鲨鱼官方图片仅作所标注平台及年代的视觉比较，不能将 iOS 导航说成 Android 现状。其他产品多账本/资产等功能不随外观引入。

决定：底部三目的地【明细／统计／设置】，主页面统一全局【记一笔】浮动操作；明细点击打开详情，详情内编辑或确认删除。成熟模式用于信息结构和操作习惯，所有图标和布局由本项目代码原创，不复制品牌标志、付费图片、字体或截图资产。

## 3. 信息结构

```text
安记账（稳定根组件，原 ViewModel 与系统文件回调）
├─ 明细 [默认]
│  ├─ 共享月份：上月 / YYYY年M月 / 下月 / 本月
│  ├─ 全月收入 / 支出 / 结余
│  ├─ 搜索分类或备注 + 全部类型 / 仅收入 / 仅支出 + 清除筛选
│  ├─ 显示 x / 本月 y 条；筛选只影响明细
│  └─ 日期倒序分组 → 账目行 → 账目详情
│                                  ├─ 返回明细
│                                  ├─ 编辑账目 → 全屏 Editor
│                                  └─ 删除 → 原确认窗口
├─ 统计
│  ├─ 同一月份与完整月概览
│  └─ 支出分类金额排行及比例条（空月明确提示）
├─ 设置
│  ├─ 备份与恢复：导出备份 / 恢复备份 / 原明文与容量告知
│  ├─ 本地隐私及卸载提醒
│  └─ 关于：版本0.1.3 / 第三方许可
└─ 全局记一笔 → 全屏 Editor → 保存/取消返回来源主页面
```

主页面切换保留共享月份、原文 query、kind；设置不显示月份，但不能重置。导航身份用稳定 key `ledger/stats/settings`，文案独立。详情是明细的二级状态，隐藏底导航和 FAB；返回明细恢复月份、筛选和滚动。点击详情编辑后，取消回详情，成功保存回明细并刷新原筛选；这样改动了分类或备注而不再匹配的记录不会留在过期详情中。删除成功回明细；失败保留详情/确认。主页面新增取消或保存回原页面；禁止保存时按完成消息或 entries 变化猜测成功。

## 4. 视觉规格

视觉方向：像一个清晰的私人账本，白色纸面、蓝色操作、紧凑有序的逐日流水。记忆点放在日期分组和右侧对齐金额，不铺相同形状的大卡片、不添加装饰渐变。所有统计金额来自现有 Long 汇总。

六个基础色：操作蓝 `#2457C5`、收入青 `#176B5B`、支出/错误红 `#B33C38`、正文墨 `#17212F`、页面灰 `#F5F7FB`、纸白 `#FFFFFF`。边线和容器色从这些角色派生；Material3 primary/secondary/tertiary/error 及其 on/container/inverse/surface 角色全部显式配置，消除原绿色主色与默认紫色混合。浅色主题，沿现有行为不增加深色开关。系统中文 sans，不下载字体、不锁 fontScale。

字号：页标题24sp、主要金额28sp、行金额18sp、分类16sp、正文14–16sp、辅助12sp；行高随 typography 和系统字体增长。内容水平16dp，主要纵间距12/16/24dp；按钮和图标目标至少48dp；页面底部保留 FAB 遮挡安全区。表单和详情可滚动，IME 上弹时可滚动找到保存和取消。大字号下金额区可换行，不能压缩字号来维持一行。

明细第一屏以月份、月概览、查询为上下顺序。流水按日期倒序，日标题显示 ISO 日期，不写依赖午夜刷新才能准确的“今天”。每行显示分类、收入/支出、金额正负号；备注最多2行，完整内容在详情。分类最多20字、备注200字、大额999999999.99都必须有实际可到达的完整详情；仅靠颜色不能区分收支。图标用原创 Canvas/代码绘制的列表、柱状统计和设置形状；同时保留文字标签和 selected 语义。

## 5. 状态与接口架构

沿用 `LedgerScreen` 作为始终挂载 root，集中持有：pageKey、monthText、query原文、kindName、detailJson、editing、editingJson、editorSessionKey、editorReturnToDetail、deletingJson、pendingSaveId、pendingDeleteId。单条 Entry 快照继续用现有 BackupCodec，不改自定义 Saver、不把数据库查询当恢复快照。Editor 的 `key(editorSessionKey)` 隔离每次打开；该 key 本身 rememberSaveable，重建不生成新 key。

页面组件只消费数据与回调。`EntryGroups.forDisplay(List<Entry>): List<EntryDay>` 仅 presentation，按 date DESC 分组，同日保留原输入相对次序，不修改输入或记录字段，不重新计算账目金额。统计始终 `MonthlySummary.calculate(state.entries, month)`，明细独立 `EntryFilter.apply`，不能误用 filtered entries 统计或导出。

操作消费保留匹配规则：只有 completedOperationId 等于对应 pending ID 才结束会话；失败、旧成功、重新打开都不误关闭。每次打开清对应旧 pending；保存/删除已提交后重建仍由同一 Activity VM 执行。root有效busy = VM busy 或 pendingSaveId/pendingDeleteId非空；save/delete返回ID即同步锁定提交，避免等待IO获取Mutex前重复点击。失败结果增加failedOperationId且按ID释放pending，不能依赖短暂busy变化或错误字符串变化。保存 busy 时 Editor 字段沿用可编辑语义，但提交的是点击时的 candidate 快照；保存/取消/返回禁用，不能重复提交。全屏 Editor 继续 Dialog(usePlatformDefaultWidth=false)，不把编辑器塞入会被主导航卸载的页面。IME 的系统 Back 先收键盘；随后非 busy Back 等同取消。

VM 每个实例生成独立 instanceId；root 的 pendingOwner 随 UI 保存。相同 VM 的 Activity 重建保留 pending 锁及正在执行的操作。保存 UI 状态恢复到新 VM 时，owner 不匹配仅清旧 pendingSaveId/pendingDeleteId，更新 owner；保留草稿、详情、编辑会话、页面、月份和筛选，等新 VM 真实读取完成后允许取消或重试。恢复不自动重放保存/删除，也不凭旧完成结果结束会话。两个 StateRestorationTester 用例验证保存 UI 状态加新 VM 的恢复路径；它们不实际杀 Android 进程，不替代作者手机生命周期验收。

全局进度/错误/重试读取/操作消息由 root 管理，当前主页面顶部能发现；Editor 内显示保存错误；删除确认内显示删除错误。重要错误不只放瞬时 snackbar。三个主页面有独立 LazyListState，详情与 Editor 独立滚动。MainActivity 的系统文件 launcher、整本导出/验证合并、明文告知和许可原样沿用。

## 6. 验收标准

A01 明细/统计/设置 selected 状态、标题及重建后的当前目的地相符；每处主页面的记一笔可达。
A02 日期倒序分组，同日相对次序稳定；原记录及原搜索次序契约不变。
A03 月份1900-01至9999-12边界及本月复位可用；原 query（含前后空格）、kind切页切月重建不变。
A04 全月统计不受筛选影响；空月份与无匹配不同；清除同时清query与kind且不改月份。
A05 详情可读每个字段，返回保留上下文；详情编辑取消回原详情，保存成功回明细，取消没有数据库写入。
A06 Editor 全屏、字段验证/类型重选/默认今天/UTC DatePicker 规则保持；全字段重建后原样保存同ID；A取消后B没有草稿泄漏。
A07 原保存/删除运行中重建、同VM、10秒等待、错误保留和旧完成隔离用例全部保留；busy Back不关闭在途会话。保存 UI 状态恢复到新 VM 后不遗留永久提交锁；草稿可取消或同 ID 重试，删除可取消且重试仅删除目标。
A08 窄屏360dp与fontScale2.0在真实CI AVD执行，页面/筛选/金额/完整备注、Editor保存取消与错误均实际显示可操作，测试finally还原设备设置。
A09 设置内明文、50000条/10MiB、事务合并冲突、卸载/云备份关闭、许可都实际可到达；警示取消不改账本。
A10 0.1.2/code3固定ff8479f→0.1.3/code4同CI证书替换；schema1/全部字段/跨月统计不变，raw runner唯一OK及CODE -1门禁不变。
A11 本机交付包同原本机debug签名、无联网/广泛存储权限、原完整许可和备份规则，旧APK不覆盖；交付SHA256、实际测试数量、截图及限制。
